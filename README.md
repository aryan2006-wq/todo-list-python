# todo-list-python
Simple command line To-Do list in Python using file handling

Ek command line To-Do app jisme tasks file mein save hote hain.

## Features
-  Add Task 
- view all tasks 
- close it
- Data `todo.txt` mein save hota hai, to program band karne ke baad bhi bacha rehta hai

## Kaise chalayein
python todo.py

## Kya seekha
File handling, loops, if-elif-else, try/except
