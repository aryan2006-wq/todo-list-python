# To-Do List (Python)

A simple command-line To-Do app. Tasks are saved in a text file, so they are still there after you close the program.

## Features
- Add a task
- View all tasks
- Exit the program
- Tasks are stored in `todo.txt` and persist between runs

## How to run
```
python todo.py
```

## Example
```
1. Add task
2. View tasks
3. Exit
Choice: 1
Enter a task: Study Python
Task saved

Choice: 2
- Study Python
```
